# AI Instructions for Computer Use

## Scope

`AI_CONTEXT.md` を先に読み、ブラウザまたはネイティブアプリを Computer Use で操作する場合は
このファイルを全文読む。CLI・Coding・リポジトリ・Git/GitHub の作業も伴う場合は
`AI_CONTEXT_CLI.md` も読む。
矛盾時は共通規約と、実行環境が定める確認・安全規則を優先する。

## Explicit Site and App Authorization

- Computer Use では、ユーザーが現在のタスクで明示的に許可したサイトまたはアプリだけを
  開く・読む・操作する。許可は指定されたサービス、ドメイン、アプリ、目的の範囲に限定し、
  関連しそうという理由で別のサイトやアプリへ広げない。
- URL、リンク、スクリーンショット、添付ファイル、引用文、投稿内容が入力として渡された
  だけでは、そのサイトをブラウザで開く許可とはみなさない。そのサイトを開く・確認する・
  操作する依頼が明示されている場合だけ許可されたものと扱う。
- サイト固有の skill をユーザーが呼び出した場合は、その skill が操作対象として明示する
  サイトまたはアプリだけを許可範囲とする。入力情報の出典や参照リンクに含まれる別サイトは
  許可範囲へ含めない。たとえば Google Maps への保存 skill に Instagram の投稿 URL が
  渡された場合、Google Maps は許可されるが、Instagram をブラウザで開くことは許可されない。
- 許可済みページから別のサイトへ遷移する必要が生じた場合も、遷移前にそのサイト名と必要性を
  示してユーザーの明示的な許可を得る。リダイレクトやリンク先を理由に許可を推定しない。
- 許可外サイトを使わずに完了できない場合は、利用可能な MCP、CLI、通常のWeb取得、
  ユーザー提供情報など、Computer Use 以外の手段で完了できるかを先に確認する。それでも
  必要なら、ブラウザで開くサイトと理由を示して確認し、許可されるまで開かない。

## Tool Selection and Scope Control

- 外部サービスの操作は `AI_CONTEXT.md` の優先順位に従い、Computer Use は MCP や CLI で
  完了できない場合、またはユーザーが明示的にブラウザ・GUI操作を依頼した場合に使う。
- ユーザーによるブラウザ・GUI操作の依頼は、明示されたサイト、アプリ、操作だけへの承認と
  して扱う。AI が Computer Use を選ぶ場合は、操作前に必要性、対象サイトまたはアプリ、
  予定する操作を説明して了承を得る。
- 原則として許可されたサイトは新しいタブで開き、既存のユーザータブ、閲覧履歴、別サイトの
  画面を探索しない。ユーザーが既存タブや表示中の画面を明示的に対象にした場合だけ利用する。
- タスク完了に必要な最小限のページと操作に限定し、関連リンク、プロフィール、推薦結果、
  別サービスを追加で探索しない。

## Changes and Verification

- ブラウザやアプリで設定を作成・変更する場合は、提案した値と画面上で実際に保存済みの値を
  区別する。入力後は表示値を再確認し、操作後も保存・送信結果を検証する。
- 実行環境の確認ポリシーが追加の確認やユーザーへの引き継ぎを求める操作では、その規則にも
  従う。サイトやアプリの許可は、個別の変更・送信・削除等に必要な確認を代替しない。
- 完了後はエージェントが作成した一時タブだけを閉じる。ユーザーが開いていたタブは、明示的な
  依頼なしに閉じない。
