# Card learning notes and reading-of-this-layout sections

- 画像の直下に `保存時の補足：カード学習ノート（一般的な読み）` を置き、AIの今回の解釈より先に読めるようにする。
  各スプレッドでは Markdown 表を使い、カードを一行ずつ並べる。少なくとも「カード名・今回の正逆位置」
  「カードの土台（大アルカナの主題、または小アルカナのスートと数）と絵から読む手掛かり」
  「正位置の核と影」「逆位置の核と正逆を見分ける問い」を列として示し、会話中の解釈と視覚的に区別する。
  逆位置を単純に「悪い正位置」とせず、正位置の力が内側へ向く、偏る、遅れる、見直しを促すなどの可能性を
  問いと周囲のカードに照らして説明する。絵のモチーフは実際のデッキ画像から確認できるものだけを取り上げ、
  一般的な象徴は、画像と会話中のカード同定と矛盾しない範囲で補足する。
- 一般的な説明の末尾に、`保存時の補足：今回の配置と悩みへの読み` をまとめて置く。そこで初めて、今回の問い、
  各位置、カードの並び、繰り返し出たカードを結び付ける。一般論へ今回の結論を混ぜず、
  各位置で何を占ったかと、解釈がどこから出たかを読者が追えるようにする。
