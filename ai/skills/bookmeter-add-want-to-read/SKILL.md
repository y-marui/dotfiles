# Add to Bookmeter Want-to-Read (読みたい本)

タイトル・著者・画像・URLなどから本を特定し、ジャンルに応じた読書メーターアカウントで登録状況を確認する。「読んだ」「読んでる」「積読」「読みたい」のいずれにも未登録の場合だけ「読みたい本」に追加する。

## Determine the account

- ジャンル別のアカウント対応表は `~/.identity/bookmeter-accounts.yaml`（dotfiles-private で管理、`genre`/`label`/`display_name` を持つ）を読む。ファイルがなければ作成方法を説明してユーザーに確認し、停止する。
- ジャンル判定の既定ルール:
  - 小説・エッセイ・一般書（新書を含む）は既定で `novel` ジャンルとして扱う。
  - 物理学・数学などの理学書、および研究・専門用途が明らかな新書やその他の書籍は `science` ジャンルとして扱う。
  - 新書は既定で `novel` だが、内容が研究関連だと判断できる場合は `science` にする。
  - 著者・出版社・内容紹介から判断しても本のジャンルが決まらない場合は、追加前にユーザーに確認する。
- ユーザーがログイン済みのブラウザ状態を使う。認証情報は扱わず、ログインやアカウント切り替えはユーザーに依頼する。
- 操作前に、画面右上のバナー（例:「(表示名)さんのマイページ」）で、対象ジャンルに対応する `display_name` のアカウントが実際にログイン中であることを確認する。一致しない、またはログインしていない場合は、何も登録せずユーザーにアカウントの切り替え・ログインを依頼して停止する。

## Identify the Work

- タイトル・著者名・ISBNなどで検索し、候補を絞る。
- タイトルだけでは一意に定まらない場合（上下巻、文庫版/単行本違い、同名異著者など）は、著者・出版社・巻数・あらすじで照合する。ユーザーが特定の版を指定していればそれに従う。
- 十分に特定できなければ追加せず、不足する情報をユーザーに尋ねる。

## Check Status on Bookmeter

- 本の詳細ページ、または検索結果の「本を登録する」から、本棚登録ウィジェット（「読み終わった本に登録する」「読んでる本に登録」「積読本に登録」「読みたい本に登録」の4択）を開く。
- 現在ハイライトされている（色付きの）選択肢が、その本の現在の登録状態を示す。どれもハイライトされていなければ未登録。
- 1つ目の選択肢のラベルが「読み終わった本に登録する」ではなく「再読した本に登録する」になっている場合、既に「読んだ」として登録済みであることを示す。
- 判定に迷う場合はスクリーンショットとアクセシビリティツリーの両方で確認する。

## Process

1. 4つの状態のいずれかが既にハイライトされている（＝既に読んだ／読んでる／積読／読みたいのどれかに登録済み）場合は、何も変更せずその状態を報告する。読みたいへの重複登録もしない。
2. どれも未登録の場合だけ「読みたい本に登録する」を押す。登録後、その選択肢がハイライトされたことを再確認する。他の選択肢（読んだ・読んでる・積読）には触れない。
3. 状態を判定できない、操作が失敗した、または追加後のハイライトを確認できない場合は完了と報告しない。
4. レビュー、評価、感想、タグ等、登録状態以外の項目は変更しない。

## Report

日本語で簡潔に、書名・使用したアカウント（表示名）・結果を伝える。

- 追加した場合: 「『書名』を(表示名)アカウントの読みたいに追加しました。」
- 既に登録済みの場合: どの状態（読んだ／読んでる／積読／読みたい）で登録済みかを明記する。
- ジャンルやアカウントの選択が曖昧だった場合は、判断根拠と共に確認を求めたことを伝える。
