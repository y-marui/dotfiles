# Images requested for a note

- 調査ノートに画像を求められた場合、生成画像は明示的に求められたときだけ使う。実在の場所・資料を示す目的なら、ネット上から**参考になる少数**の写真を選ぶ。
- ローカルへ保存する画像は、作者、再利用条件、元ページを確認できるものだけにする。ノート内に各画像の出典とライセンスを記録し、出典やライセンスが確認できない画像は保存せず元ページへのリンクにとどめる。
- 埋め込み画像は、ノートと同じ階層の`<ノート名>-img/`へ置く（`path/to/note.md`なら`path/to/note-img/`）。
  Privateのノートの画像もそのノートの隣に置く。ノートに埋め込まない小さな参照ファイルは
  `<ノート名>-assets/`とし、トップ階層の`assets/`は使わない。規則の正本はvaultの
  `docs/vault-architecture.md`の「添付ファイル」とし、食い違う場合はvault側を優先する。
  既存Legacyノートを更新する場合も、リンク切れを防ぐため既存の画像配置は壊さず、移す場合は
  リンクのパスを同時に更新する。1つの`-img/`は原則として1つのKnowledgeだけが所有する。
- ファイル名は`Pasted image`のような既定名を避け、内容が分かる名前にする。
- ノート本文では、代替テキスト付きのMarkdown相対リンク（`![代替テキスト](note-img/file.jpg)`）で
  画像を参照する。外部画像URLの直埋め込みは、表示切れや利用条件確認を避けるため使わない。
- 画像は主題の理解を助ける分だけに絞る。画像の収集自体が主目的でなければ、地域・候補ごとに機械的に追加しない。
