# Cinema Skills

仙台の上映作品の発見と、選んだ映画のタスク登録を分離する。

| Skill | 用途 |
| --- | --- |
| `cinema-check-sendai` | TOHO仙台・MOVIX仙台・フォーラム仙台の上映中／告知済み予定を調べ、画像・あらすじ・推薦理由・各館の期間付きで紹介 |
| `glance-task-add-movie` | 推薦から選んだ作品、タイトル、URLから映画を同定し、Glance Taskの「映画」へ追加／更新 |

## Installation and Use

`make links`が`ai/skills/`の2フォルダを自動検出し、Claude CodeとCodexの共通skillへリンクする。
`make check`でリンクを、`make check-skills`でskill構造と同梱テストを検査する。

呼び出し例:

- 「仙台で上映中・上映予定の映画をチェックして」
- 「映画の好みを更新して」
- 「この映画をGlance Taskに登録して」

推薦は手動実行。上映中と上映予定それぞれ本命3〜5本＋意外な候補1〜2本を目安とし、
不足時は無理に埋めない。期間は公式情報を使い、終了日不明を推定しない。
上映時刻表の最終日と上映終了日、全国公開日と各館の開始日を区別する。

## Personal Data

個人の好みは公開リポジトリへ含めず、既定vaultの`knowledge/movie/preferences.md`に保存する。
初回または明示的な更新依頼時に、Filmarks映画Marksの複数ページの本人評価・レビューから推定する。
「観たい」は読まない。全鑑賞履歴の保存・毎回の差分収集・厳密な既見照合は行わない。
プロフィールの未確認推定と、本人が確認した好みを区別する。保存形式と分析手順は推薦skillの
`references/profile.md`を参照する。

## Glance Task Contract

macOSのGlance TaskとPython 3.11以上を使う。標準位置以外のAppは`GLANCE_TASK_APP`で指定する。
登録依頼時に対象グループ「映画」を安定IDで解決する。グループが未作成ならUIで作成するか、
利用できない場合は作成を依頼する。AppleScriptにグループ作成命令はない。

- タイトルは`映画名 (10/23〜)`。日付不明は映画名だけ。
- 年を含む日付、映画館別期間、Filmarks・公式URL、確認日、構造化データをメモへ保存する。
- 開始日の昇順、日付不明は末尾。同日は既存の相対順を保持する。
- 複数館では最も早い開始日。3館の予定が未確認の場合は国内公開日を代用し、区別を記載する。
- 新規に期限を設定せず、更新対象の既存期限は外す。表示位置は`task position`で検証する。
- 同一作品の未完了は更新。完了済みだけなら報告し、明示的な再登録時だけ新しいタスクを作る。
- 完了済みとサブタスクは変更しない。未管理タスクの同定・日付は推測しない。
- 生成メモの末尾へ空行で区切って追加された本人メモは更新時も保持する。
  生成部分の手編集は上書きせず、内容を確認してから扱う。

入力形式・プレビュー・適用は登録skillの`references/input.md`とCLIの`--help`を参照する。
推薦だけでは登録しない。検証に実データの追加を使わない。

## Verification and Recovery

同梱テストは並び順・重複・日付属性なし・本人メモ保持・部分失敗を模擬アプリで確認する。
AppleScriptの実機確認にはGlance Taskのインストール・認証・Automation権限が必要。

書き込みが失敗した場合はグループを再取得し、返却済みIDとタイトル・メモ・positionを確認する。
作成を無条件に繰り返さない。グループの並び替えや更新は複数のアプリ操作なので、途中失敗時は
部分適用になり得る。生成メモの構造化データを使って再プレビューし、完了済み・サブタスク・
他者変更を巻き込まずに再開する。
